# 仪表盘待复习提醒去重设计

## 背景与根因

薄弱点复习流程已简化为“待复习 / 已掌握”，不再使用分阶段的预期复习次数。仪表盘仍直接逐条查询并展示历史 `ReviewSchedule` 记录，因此同一学生的同名薄弱点可能由多条历史计划重复出现，同时页面右侧仍显示旧版“第 N 次”文案。

## 目标行为

- 仪表盘对到期且状态为 `pending` 的复习计划进行展示层去重。
- 去重键为“学生 ID + 规范化后的薄弱点名称”；规范化时去除首尾空格、合并连续空白并转为小写。
- 每组保留查询结果中最早到期的一条，保持提醒顺序稳定。
- 顶部“待复习提醒”数量与下方去重后的可见提醒数量一致。
- 提醒行仅显示“逾期 / 待复习”状态、学生姓名和薄弱点名称，不再显示“第 N 次”。

## 实现边界

本次只修正仪表盘查询结果的整理与展示，不删除历史数据，不改变学习进度页的复习操作，也不改变复习计划的状态更新逻辑。这样可兼容旧数据，避免为解决展示问题而破坏历史记录。

## 验证

- 增加仪表盘回归检查，覆盖同学生同名提醒去重、不同学生不误合并、顶部计数使用去重结果，以及页面不再渲染复习阶段。
- 运行项目现有薄弱点复习检查、类型检查和生产构建，确认无回归。
