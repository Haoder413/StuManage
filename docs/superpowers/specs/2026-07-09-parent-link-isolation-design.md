# Parent Link Isolation Design

## Goal

家长端时间管理、成绩记录和学习进度按本轮确认的学习关系口径展示，避免家长个人安排误绑定老师，也避免不同老师、科目或课程的数据混在一起。

## Confirmed Behavior

- 时间管理：点击“新增个人安排”或编辑个人安排时，弹窗不再显示“学习关系”下拉。个人安排仍选择孩子、科目、日期、时间、重复规则和备注；保存时不绑定老师或学习关系。
- 成绩记录：提交成绩继续通过学习关系下拉选择老师、学生和科目。成绩分析、考试明细、成绩趋势图和家长提交记录都按当前选择的学习关系过滤。
- 学习进度：页面提供学习关系筛选，按当前选择的学生、老师、科目或课程展示知识点进度和薄弱点复习。
- 老师结课后给学生新增课程并导入新知识框架时，家长端选中新学习关系后只显示新课程知识框架；旧课程不混入当前学习进度。旧学习关系仍启用时可切回查看历史；停用后不再作为家长端入口展示。

## Data Flow

- 家长可用学习关系来自 `LearningLink`，条件为当前工作区、当前家长、`isActive=true`。
- 个人安排 `ParentScheduleItem` 仍归属 `parentId` 和 `studentId`，但新建和编辑不再写入 `learningLinkId`。
- 成绩 `Exam` 以 `learningLinkId` 区分老师和科目。
- 知识点进度 `StudentKpProgress` 和薄弱点 `WeakPoint` 以 `learningLinkId` 区分老师和科目；课程知识点大纲从当前学习关系绑定课程读取。

## Error Handling

- 没有学习关系时，成绩记录和学习进度展示空状态，提示先联系老师或管理员配置学习关系。
- 个人安排保存仍校验家长是否拥有该学生，防止绕过页面写入其他学生。
- 成绩和学习进度的学习关系筛选只接受当前家长启用的学习关系。
