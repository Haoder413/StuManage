# 课程视频 CDN 鉴权设计

## 目标

课程视频仅允许已登录且通过现有课程权限检查的账号播放，同时让视频正文由腾讯云 CDN 缓存和分发，避免浏览器直连 COS 产生大量外网下行流量。

## 已确认方案

采用腾讯云 CDN Type D URL 鉴权和私有 COS 回源。播放链接有效期为 2 小时。鉴权密钥只配置在服务器共享环境文件中，不提交到 Git。

## 播放流程

1. 浏览器请求现有课程视频播放接口。
2. 服务端继续使用 `requireCurrentUser` 和 `canAccessLessonVideo` 检查登录状态与课程权限。
3. 权限通过后，服务端为 CDN 视频路径生成 Type D 临时地址，格式为 `https://域名/文件路径?sign=摘要&t=时间戳`。
4. CDN 校验签名和有效期。无签名、签名错误或过期请求返回 403。
5. CDN 命中缓存时直接返回视频；未命中时使用腾讯云授权从私有 COS 回源。
6. 浏览器不再获得 COS SecretId、SecretKey 或 COS 对象签名。

## 签名规则

- Type D 摘要遵循腾讯云规则：`MD5(鉴权密钥 + 文件路径 + 时间戳)`；鉴权密钥必须为 6 至 32 位字母或数字。
- 时间戳默认使用十进制 Unix 时间戳，与控制台选择保持一致。
- 文件路径使用以 `/` 开头的原始对象路径，签名输入与实际请求路径必须完全一致。
- 有效期由 CDN 控制台设置为 7200 秒；程序只写入当前签发时间，服务器与 CDN 节点必须保持自动校时。

## 环境变量与兼容切换

新增独立的 CDN 鉴权启用开关和鉴权密钥，并复用现有 CDN 播放域名。只有启用开关、域名和密钥同时有效时才生成 CDN 鉴权地址。

首次部署时保持鉴权开关关闭，继续使用现有 COS 签名兼容路径，因此不会影响线上播放。完成腾讯云控制台配置后再打开开关并重启应用。若切换验证失败，可关闭开关立即回退，不需要修改数据库。

## 腾讯云配置顺序

1. 部署支持 CDN Type D 鉴权的程序，但暂不开启应用鉴权开关。
2. 在服务器写入符合限制的鉴权密钥，应用鉴权开关继续保持关闭。
3. 开启 CDN 的私有存储桶访问/回源鉴权并验证旧 COS 签名地址仍可播放。
4. 打开应用鉴权开关并重启服务，使程序开始生成 Type D 地址并验证播放。
5. 在 CDN 控制台开启 Type D URL 鉴权，使用与服务器相同的密钥、时间戳格式和 2 小时有效期。
6. 验证有效链接返回视频、无签名链接返回 403、过期或错误签名返回 403。

私有回源必须先于应用 Type D 地址启用，否则私有 COS 会拒绝不再携带 COS 签名的回源请求。应用应先于 CDN URL 鉴权启用 Type D 地址；回滚时先关闭 CDN URL 鉴权，再关闭应用开关。

## 缓存策略

视频节点缓存保持 30 天。鉴权参数不应形成独立缓存副本；当前视频域名只承载原始视频文件，可以继续忽略查询参数。若以后同一路径通过查询参数返回不同内容，需要收紧缓存键规则。

## 错误处理

- 登录或课程权限不通过：保持现有 401/403 行为，不生成播放地址。
- CDN 鉴权配置不完整但开关关闭：继续走兼容路径。
- CDN 鉴权开关开启但密钥或域名缺失：服务端记录明确配置错误并拒绝生成不安全的公开地址。
- CDN 返回 403：通过关闭应用开关回退，并核对密钥、时间戳格式、服务器时间和签名路径。

## 测试与验收

自动测试覆盖：Type D 摘要计算、对象路径安全编码、签发时间格式、配置关闭时的兼容路径、启用但缺少密钥时拒绝降级。两小时过期行为由腾讯云鉴权计算器和线上过期链接验证。

线上验收覆盖：正常播放和拖动进度条；无签名、篡改路径、篡改签名和过期链接均返回 403；CDN 监控出现下行流量，COS 主要表现为少量 CDN 回源流量而非大量外网下行流量。
