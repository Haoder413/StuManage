# 小数课时设计

## 目标

课时相关操作允许最多两位小数，例如 `0.5`、`1.25`，并确保排课扣减、手动增减及管理员修改历史记录的行为一致。

## 设计

- 新增统一课时工具，负责解析、校验和四舍五入到两位小数。
- 课时数量必须是有限数字；扣减/增加数量必须大于 0；历史记录变化量允许为 0 或负数。
- 学生课时与课时流水字段由 Prisma `Int` 改为 `Float`。SQLite 迁移保留现有整数值。
- 所有前端课时输入使用 `step="0.01"`，提交时不再使用 `parseInt`。
- 接口在保存前统一校验最多两位小数，并在加减计算后归一化，避免浮点尾数进入页面和流水。
- 部署脚本只在显式传入一次性开关时确认 Prisma 类型迁移；执行结构同步前仍会备份并校验数据库。

## 验证

- 自动检查 `0.5`、`1.25` 可用，三位小数、非数字及非正扣减被拒绝。
- 验证 Prisma schema、三个输入入口及接口均已切换为小数处理。
- 运行 Prisma 校验、现有课时检查、TypeScript/构建检查。
